Unlisted has five parts. Only the program holds or moves value; everything else reads the chain or builds transactions for a wallet to sign.

| Part | Where | Runs on | Does |
|---|---|---|---|
| **The `basket` program** | `programs/basket/` | Solana devnet | Holds the vault, mints and burns shares, records claims. No price anywhere. |
| **The SDK** (`@unlisted/sdk`) | `sdk/` | the browser and scripts | Decodes accounts and events, reproduces the share maths, builds every instruction and packs flows into transactions |
| **The valuation API and issuer watcher** | `services/valuation/` | Railway | The three labelled values, quotes, and every issuer change with its transaction |
| **The web app** | `web/` | Vercel | The landing page, `/evidence`, and the holder app at `/app` |
| **Devnet fixtures** | `fixtures/` | Solana devnet | Seven mints that mirror the PreStocks mints, fixture USDC, the `fixture_amm` router, a hook program |

## How they talk

```
             wallet (signs)
                  ▲
                  │ unsigned transactions
   ┌──────────────┴───────────────┐        three values, quotes,
   │  web app (/app) + SDK        │◄────── issuer and program events ────┐
   │  in the visitor's browser    │                                      │
   └──────┬───────────────────────┘                                      │
          │ reads accounts, sends transactions                           │
          ▼                                                              │
   ┌─────────────────────────────┐   reads     ┌─────────────────────────┴──┐
   │ Solana devnet               │◄────────────┤ valuation API + watcher     │
   │  basket program             │             │ (Railway)                   │
   │  fixture mints, fixture_amm │             └─────────────┬───────────────┘
   └─────────────────────────────┘                           │ reads (never signs)
                                                             ▼
                                              Solana mainnet: the real PreStocks
                                              mints, Jupiter quotes and prices,
                                              the issuer's multisig
```

- **The browser reads devnet directly.** The app gets its settings from `/config.json` (cluster, program, share mint, lookup table, router and the valuation API's URL). It refuses any cluster but devnet or localnet.
- **The wallet signs; nothing else does.** The SDK turns a user flow into unsigned transactions, and the app hands all of a flow's transactions to the wallet in one signing request.
- **Values come from the valuation API.** The program has no price, so the app asks the API for the three values and prints the API's `pricing_basis` next to them.
- **Mainnet is only read.** The valuation service reads the real mints, Jupiter's quotes and prices, and the issuer's multisig. Nothing in the project signs on mainnet.

## The program

An Anchor 0.32.1 program, `GyiHodshTGFo7hXSXGQiHLTCzH9yF2QWWHy6s7sm6QQv` on devnet. Its accounts, seeds and instructions are on [The protocol flow](/protocol/flow/); its deploy, errors and events on [The program](/protocol/program/).

Its only outside calls are to Token-2022 and the classic token program, the associated-token program, and whatever router is in its allowlist, which it trusts for nothing ([Routers](/protocol/flow/#routers-trusted-for-nothing)).

## The SDK

`sdk/` is a TypeScript package, `@unlisted/sdk`:

- **Decoders** for the program's accounts and events, hand-written from spec 02 and compared with the generated IDL by `scripts/idl-check.ts`.
- **Share maths** (`src/math.ts`): pure integer functions that must match the reference model to the unit. The tests replay vectors generated by `spec/model/`.
- **Token-2022 reads** (`src/token2022.ts`): the transfer fee now and pending, the effective multiplier, and availability, parsed from the mint's extension data exactly as the program reads it.
- **Instruction builders** and **flows** (`src/flows.ts`), which pack a deposit or redemption into transactions by serialized size.
- **Routers** for `fixture_amm` and Jupiter.
- **A polite fetch** for rate-limited public RPCs.

## The valuation API

`services/valuation/` implements spec 03 as a plain Node HTTP server, deployed on Railway.

| Endpoint | Returns |
|---|---|
| `GET /v1/basket` | Basket state and the three values for one whole share |
| `GET /v1/position/{owner}` | A wallet's shares, open tickets and claims, valued at that wallet's size |
| `GET /v1/quote/redeem?shares=&mode=` | What redeeming now would pay per leg, including the claims it would create |
| `GET /v1/quote/deposit?usdc=` | The per-leg USDC split, expected deltas, minimum outputs and expected shares for a ticket deposit |
| `GET /v1/capacity?max_round_trip_bps=` | The largest size under a round-trip cost threshold |
| `GET /v1/events?since_slot=` | Program events and issuer events, newest first |
| `GET /v1/issuer` | Live issuer controls per leg, for the fixture and the mirrored mainnet mint |

**Every figure says where and when it was read**: a `source` and an `as_of` slot or time.

**The issuer watcher** polls the mainnet PreStocks mints and the devnet fixture mints. It emits one event per change, with the before and after values and the transaction that made it: `FeeChangeScheduled`, `MultiplierChangeScheduled`, `Paused` / `Resumed`, `HookSet`, `DefaultStateChanged` and `MultisigConfigChanged`.

- It scans the issuer authority's transactions (on mainnet, the Squads vault), including instructions the multisig executes internally.
- On every poll it also compares each mint's state with the last snapshot. A change that no scanned transaction explains is still emitted, without a signature, so a missed transaction can't hide a change.

**Cold start.** `/v1/basket` is recomputed in the background and served from the latest completed computation, which is also saved to disk. A restarted service answers from the saved basket at once, marked `served.from: "cache"` with its age, while a fresh one is computed (`docs/deploy.md`).

**Checked against the chain** ([Evidence](/trust/evidence/#the-valuation-api-matches-the-chain)): `/v1/basket` matched an independent decode of the account bytes on all 114 fields, and `/v1/quote/redeem` matched real devnet redemptions to the unit on every leg.

## The web app

`web/` is a Next.js site on Vercel: the landing page at `/`, the transaction list at `/evidence`, and the holder app at `/app`.

- **Its build checks its own evidence.** Before every build, `scripts/verify-evidence.mjs` checks that every signature in `lib/evidence.json` is finalized without error on its network, and at its recorded slot where the record gives one.
- **The devnet RPC key is visible in the browser.** A client-side app has to hand the browser its RPC URL, so `/config.json` includes the Helius devnet URL with its key. The key is never committed; it's built from an environment variable at request time. `docs/deploy.md` records restricting the key to the site's domain as still to do.

The app is being restructured as these docs are written; a guide to what you see in it will follow on its own page.

## Devnet fixtures

On devnet the issuer is played by a **fixture issuer** key, `3kJFLzxPYt5CHtM4cpzTfjpKKdVz2d2k29F3PkmtAWH3`, which holds every fixture authority. It stands in for PreStocks' multisig.

- **Seven fixture mints**, each with the same Token-2022 extension set as its PreStocks mint, the same fee now and pending, and the same effective multiplier. `fixtures/DIFF.md` lists every remaining field difference and why (authorities, supply, metadata strings, epoch numbering), from live reads at mainnet slot 450,170,407 and devnet slot 503,694,628. Its `--check` mode fails on any mismatch.
- **Fixture USDC** (classic SPL, 6 decimals): `5qD6fWLePJ8MiFDa3er38G76RHY53VatQUNZRm7i8M15`.
- **`fixture_amm`** (`aznyZehUyR37Zr9iRM22jgWoPQ43PznYB9TDUxYMTqF`): constant-product pools of fixture USDC against each leg, seeded from mainnet prices. It's the devnet router.
- **A hook program** (`5GyNwRXdvWDuQLDaYKnirNH35hwWZdun7mZ3m6bGdHEJ`), for switching a transfer hook on.
